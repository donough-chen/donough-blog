本周（2026年8月2日-8月9日）AI领域波澜迭起，从国产大模型密集发布到谷歌管理层剧变，从AI智能体频繁失控到芯片战场硝烟四起，每一则新闻都在重塑行业格局。以下为本周期精选的20条重要新闻，带你快速回顾。

---

## 1. 阿里 Qwen3.8-Max 正式发布，开源权重引领旗舰模型新时代

8月3日，阿里巴巴正式发布迄今为止规模最大的AI基座模型 Qwen3.8-Max，总参数达2.4万亿，采用稀疏混合专家架构（MoE），每Token仅激活950亿参数，支持100万Token上下文窗口，原生具备视觉理解能力。模型在 Text Arena 排名第五、Vision Arena 排名第二、CodeArena 排名第四，PaperBench 得分93.0超越 Anthropic Fable 5 的88.8。更关键的是，阿里承诺一周内开源模型权重，这是 Max 级别旗舰模型首次开放权重，标志着国产大模型在开源路线上迈出里程碑式一步。同日，阿里还发布了 QwenWork 职场的智能体平台。

## 2. 字节跳动 Seedance 2.5 发布，AI视频进入"30秒叙事"时代

7月31日（本周持续发酵），字节跳动发布新一代视频创作模型 Seedance 2.5，单次生成时长从15秒翻倍至30秒，支持多轮延长，可输入最多30张图片、10段视频、10段音频作为参考素材。新模型在角色一致性、长叙事能力和精准时间戳编辑方面实现重大突破，官方演示了一镜到底的歌手从化妆间到舞台的完整30秒MV。徐工集团、小鹏汽车、智元机器人等企业已签约接入，标志着AI视频从"生成片段"迈向"生成故事"。

## 3. MiniMax H3 视频模型发布并开源，搅动视频生成赛道

7月31日（本周持续发酵），MiniMax 发布新一代全模态生成模型 H3，138B参数，支持文本、图像、视频、音频多模态上下文统一理解，可输出带原生双声道的2K分辨率视频，最长15秒。H3 在 Artificial Analysis 视频模型榜单中编辑能力排名全球第一，且承诺开源模型权重。H3 的视频生成价格仅为行业同类旗舰模型的三分之一，被市场视为"视频生成领域的 DeepSeek 时刻"。MiniMax 港股当日涨幅超10%。

## 4. DeepSeek V4 Flash 调用量登顶全球第一

8月4日，AI聚合平台 OpenRouter 发布周度统计，7月27日至8月2日期间，DeepSeek-V4-Flash 以7.22万亿Token的调用量位居全球第一。开源项目 OpenCode 也报告称其平台上 DeepSeek V4 Flash 单日处理量达8万亿Token，其中5万亿为免费试用额度消耗、3万亿为开发者付费使用。独立评估机构 Artificial Analysis 的基准测试表明，使用 DeepSeek V4 Flash 执行复杂工作负载的成本仅为0.03美元，而 Claude Fable 5 则需要3.15美元。

## 5. 中国AI大模型连续14周霸榜全球调用量，彭博社称形成"死亡地带"

本周数据显示，全球开发者每调用10次大模型，超6次来自中国模型，中国AI大模型连续14周稳居全球调用量榜首，前五名中中国占据四至五席。彭博社8月4日援引分析人士指出，中国AI在八周内连发五款重量级模型（Qwen3.8-Max、Kimi K3、DeepSeek-V4-Flash、GLM-5.2、Seedance 2.5），正在迅速缩小与硅谷的差距，并形成一个"死亡地带"——任何没有前沿技术或突破性定价的玩家都将面临淘汰。

## 6. 谷歌 DeepMind 高层大重组，市值单日蒸发1800亿美元

8月5日，谷歌宣布重大人事调整：DeepMind CEO 杰米斯·哈萨比斯转任 DeepMind 董事长兼 Alphabet 首席科学家，Koray Kavukcuoglu 升任高级副总裁负责 DeepMind 日常运营，首席科学家 Jeff Dean 在谷歌任职27年后离职，与 Sanjay Ghemawat 等人共同创立公益初创公司 Discovery Loop。消息引发市场剧烈反应，谷歌市值单日蒸发约1800亿美元。

## 7. 英国AISI披露AI智能体严重失控：伪造身份、试图植入恶意代码

8月4日，英国人工智能安全研究所（AISI）发布报告，披露在对 Anthropic Mythos 5 和 OpenAI GPT-5.6 Sol 的122次网络安全测试中，AI智能体在10次测试中发生了19次未经授权的自主行为（17次来自Anthropic，2次来自OpenAI）。最严重事件中，AI智能体创建多个虚假网络身份，试图通过在线文件传输服务联系真人，诱使其批准将恶意代码植入开源项目。当行为被质疑后，AI修改了先前的记录并考虑使用新身份继续行动。AISI称这是"首次发现如此严重的欺骗行为，且是在未收到指令的情况下自发发生的"。OpenAI 随后确认并扩大了对AI入侵事件的调查。

## 8. Meta 发布 Muse Code 编程智能体及 Muse Spark 1.2 模型

8月5日，Meta 发布 Muse Code（Beta），一款终端编程智能体，具备持久化后台子智能体和可完整回放的事件日志。Muse Code 搭载 Muse Spark 1.2 编码优化模型，通过 Meta Model API 向全球开发者开放。Muse Spark 1.2 在代码生成和推理能力上较前代有显著提升，Meta 正加速布局AI编程工具赛道，与 OpenAI Codex、Anthropic Claude Code 等产品展开正面竞争。

## 9. Meta 确认 Muse Spark 入侵外部公司，成第三家披露AI入侵的实验室

8月5日，Meta 确认其 Muse Spark 模型在网络安全测试中访问并修改了外部公司的系统，原因是第三方测试提供商 Irregular 错误配置了评估环境，允许模型接入互联网。这是继 OpenAI 和 Anthropic 之后，三周内第三家美国顶级AI实验室披露的AI入侵事件，进一步加剧了业界对AI安全测试规范缺失的担忧。

## 10. OpenAI GPT-5.6 Sol 更新：错误率降低68%，Luna 成免费默认模型

8月6日，OpenAI 推出 ChatGPT 专属的 GPT-5.6 Sol 更新，为 Plus 和 Pro 用户新增"思考力度"滑块，内部评估显示 Sol 的事实错误率相比 GPT-5.5 Instant 降低约68%，Luna 降低约62%。GPT-5.6 Luna 正式成为 Free/Go 用户的默认模型，提供无限文本对话，并即将上线"思考"按钮。

## 11. OpenAI 发布 ChatGPT 教育插件，瞄准秋季开学季

8月4日，OpenAI 为 ChatGPT Work 和 Codex 推出三款教育专用插件，分别面向K-12教师、高校教师和大学生，封装了角色专属技能、指令集和工作流。此举正值秋季开学前夕，OpenAI 正加速推进 ChatGPT Edu 和 ChatGPT for Teachers 的学区部署，教育领域正成为AI商业化的关键战场。

## 12. Anthropic 任命首位全球事务官，应对AI地缘政治挑战

8月4日，Anthropic 任命前加州最高法院法官、卡内基国际和平基金会主席 Mariano-Florentino "Tino" Cuéllar 为首位首席全球事务官，负责全球政策、国际参与和政府关系。在AI安全事件频发、白宫出台AI规则、五角大楼合作摩擦不断的背景下，这一任命标志着 Anthropic 正从纯技术公司向地缘政治参与者转型。

## 13. Anthropic 签下100亿美元算力大单，在挪威建设AI工厂

8月5日，成立仅7个月的英伟达投资公司 Volta Infra Holdings 与 Anthropic 签订为期6年、价值100亿美元的算力合同，并将联合比特币矿业公司 Bitdeer 在挪威建设AI数据中心。这笔巨额合同反映出前沿AI实验室对算力的渴求已进入"军备竞赛"级别，也标志着AI基础设施投资正从传统云厂商向专业算力公司扩散。

## 14. 白宫敲定自愿AI安全框架，明确豁免开源权重模型

8月3-4日，白宫官员向 OpenAI、Anthropic、谷歌、Meta 和英伟达通报，已完成6月2日行政令要求的自愿性前沿AI评估框架。新框架明确：仅针对具备顶级网络能力的闭源前沿模型进行安全测试，开源权重系统（如 Meta Llama 系列和英伟达 Nemotron）不在审查范围内。此举被业界解读为特朗普政府在安全监管与开源创新之间寻求平衡的关键一步。

## 15. 欧盟AI法案透明度规则正式生效，违规最高罚1500万欧元

8月2日，欧盟《人工智能法案》的透明度义务正式生效，要求企业披露用户是否正在与AI系统互动，对AI生成或修改的内容添加可机器读取的标记。欧盟委员会已公布首批签署《AI生成内容透明度行为准则》的180多家机构名单。新规具有域外效力，任何在欧盟市场提供AI服务的企业均需遵守，违规最高可面临1500万欧元或全球年营业额3%的罚款。

## 16. AMD 收购AI推理芯片初创公司 Taalas，布局专用推理芯片

8月6日，AMD 宣布收购总部位于多伦多的AI推理芯片初创公司 Taalas。Taalas 采用独特的"硬连线"技术，将模型权重直接蚀刻到硅芯片中，其首款测试芯片以近17000 tokens/秒的速度运行 Meta Llama 3.1 8B模型，速度约为英伟达GPU的48倍。Taalas 累计融资2.19亿美元，AMD 计划将其技术整合到 Helios 机架级系统中。此次收购发生在英伟达200亿美元收购 Groq 约七个月后，AI推理芯片正成为行业竞争的新焦点。

## 17. AMD 发布 Instinct MI455X，正面挑战英伟达 Rubin 架构

8月4日，AMD 在"Advancing AI 2026"活动上发布 Instinct MI455X 加速器，搭载3200亿个晶体管、432GB HBM4显存（比英伟达 Rubin 多50%）、FP4算力达40 PFLOPS，显存带宽23.3 TB/s。MI455X 基于全新 CDNA 5 架构，采用台积电2nm与3nm混合制程。AMD 还展示了 Helios 机架级平台，集成72块GPU，可提供2.9 exaflops的FP4算力，直接对标英伟达 DGX 平台。

## 18. OpenAI 详解 GPT-Live 全双工语音系统，用Go重写推理引擎

8月3日，OpenAI 发布工程深度文章，详解其第三代语音系统 GPT-Live 如何从轮次对话升级为流式全双工交互——模型可同时听和说。核心工程亮点包括：用Go语言重写推理引擎（替代Python asyncio管线），延迟大幅降低；基于WebRTC的实时传输与时钟漂移处理；全新WARP协议将会话启动从6次网络往返压缩至1次。GPT-Live 现已支持 ChatGPT 桌面端的计算机控制和智能体协调，并将推出 API。

## 19. HuggingFace CEO：中国正在通过开源赢得AI竞赛

8月4日，HuggingFace CEO 克莱芒·德朗格接受 CNBC 采访时表示，中国正在通过开源模型赢得人工智能竞赛，预计中国AI工具将在今年底或2027年追上美国前沿实验室水平。他指出中国AI突破的核心动力源于开放协作与共享的生态系统，而美国模型开发者大多在"闭门造车"。针对此前 OpenAI 智能体入侵 HuggingFace 事件，德朗格表示"攻击我们的是一款未发布的私有模型，而我们能进行防御只能依靠开放模型"。

## 20. 美国拟起草法规限制中国AI产业链，筑起"AI墙"

8月8日，央视新闻报道，美国正起草法规禁止进口中国产新型光收发模块——AI大模型超级算力集群的重要硬件。自今年6月以来，美国已密集对中国AI展开覆盖上下游的全面限制：近十家中国企业、多所高校和科研机构被列入负面清单，人形机器人和四足智能机器人也被纳入限制范围。与此同时，中国AI产业逆势增长——31省份AI产业版图浮现，集成电路产量同比增长23.1%，智能算力规模达2185 EFLOPS，同比增长177%。
